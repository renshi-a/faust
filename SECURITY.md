# Security policy

Faust runs code an AI assistant wrote on people's Macs, so security reports matter a great deal.
The [security model](docs/security.md) describes what Faust is meant to protect and what it
doesn't.

## Reporting a vulnerability

Please report vulnerabilities privately, through GitHub's
[security advisories](https://github.com/renshi-a/faust/security/advisories/new), not in a
public issue. Include what an attacker controls, what they gain, and how to reproduce it.

You can expect an acknowledgment within a week. Once a fix is ready, we'll agree on a date to
publish the advisory and credit you, unless you'd rather not be named.

## Supported versions

Faust is before 1.0: fixes go into the latest release only.
